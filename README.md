# 🎲 Backgammon Dice

A simple **Python Backgammon dice roller** that generates two random dice and applies the Backgammon rule for doubles.

When a double is rolled, the result is displayed as **four dice of the same value**.

## ✨ Features

* 🎲 Generates two random dice
* 🎯 Handles Backgammon doubles
* 🔢 Displays four dice when doubles are rolled
* 🖥️ Custom Unicode dice faces
* 🧩 Simple Python implementation

## 🛠️ Tech Stack

* **Python 3**
* **random**
* **CLI / Terminal**
* **Unicode text rendering**

## 🚀 Getting Started

Run the application with:

```bash

```

The program automatically generates two dice and displays the result.
